# MiniGPT

A GPT-style transformer language model built from scratch using PyTorch.

## Features
- Transformer decoder architecture
- Tokenization pipeline
- CUDA GPU training
- Text generation
- TinyStories dataset training

## Tech Stack
- Python
- PyTorch
- CUDA
- NumPy

## Results
Model capable of generating coherent text after training.
